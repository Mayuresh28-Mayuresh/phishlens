# Security policy

PhishLens is a hackathon prototype, not a production security product.

- Do not include real credentials, personal information, customer data, or confidential organizational content in issues or test fixtures.
- Do not publish API keys or secrets. If a key was committed, revoke it immediately and replace it.
- Report suspected vulnerabilities privately to the repository maintainer rather than posting exploitable details publicly.
- Keep the tool defensive: do not add code that executes attachments, follows suspicious links, or exfiltrates user input.
